# Marand

> Marand Software (Marand d.o.o., Ljubljana, Slovenia) builds cloud-native Business
> Support System (BSS) components for communications service providers. Its product line
> — Unified Product Catalog, 360 Customer / Inventory, CPQ, CRM and Multiservice
> Enterprise Billing — is built on TM Forum's Open Digital Architecture (ODA), implements
> the TM Forum Information Framework (SID), and exposes TM Forum Open APIs. Marand holds
> TM Forum Open API Gold certified member status, achieved "Ready for ODA" status in
> March 2024, and co-authored the TMF760 Product Configuration API with Orange and Amdocs
> as one of the first twenty 5th-generation TM Forum Open APIs.

## What an agent should know first

- **There is no public Marand API.** No developer portal, no API reference, no OpenAPI,
  no sandbox, no API keys, no pricing. `api.marand.com`, `docs.marand.com` and
  `developer.marand.com` do not resolve. Marand's APIs ship inside licensed BSS
  components deployed at operator customers.
- **The contracts Marand implements are published by TM Forum, not by Marand.** If you
  need the machine-readable shape of a Marand interface, read the TM Forum Open API
  specification for the relevant TMF number (github.com/tmforum-apis) — but note that
  those specifications belong to TM Forum, and a Marand deployment's base URL, auth and
  extensions are tenant-specific.
- **Engagement is enterprise sales.** The only route in is the contact form or
  info@marand.si.

## Standards conformance

- TMF633 Service Catalog Management API — TM Forum conformance certified, release 21.0/4.0,
  report dated 2022-03-29, for Unified Product Catalog.
- TMF673 Geographic Address Management API — TM Forum conformance certified, release
  21.0/4.0, report dated 2023-05-08, for Location Management.
- TMF620 Product Catalog Management API — implemented by UPC (stated inside the TMF633
  certification report).
- TMF674 Geographic Site Management API — implemented by Location Management.
- TMF760 Product Configuration API — co-authored with Orange and Amdocs; presented at
  TM Forum Digital Transformation World 2023.
- TM Forum "Ready for ODA" — awarded March 2024.
- TM Forum Information Framework (SID) — implemented across components.
- ISO 9001 (SIQ certificate Q-2254) and ISO/IEC 27001 (SIQ certificate I-097).
